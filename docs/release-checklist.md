## 🚧 지금 막혀 있는 것

**본인 확인(신원 인증)** — 구글이 "이름 + 주소가 둘 다 나오는 서류"를 요구하는데,
갖고 계신 서류들(신용카드 명세서는 이름이 가려짐, 계좌개설확인서는 주소가 없음, 전기요금은 다른 사람 명의)이
아직 조건에 안 맞아서 막혀 있어요.

**시도해볼 것 (우선순위 순):**
1. **카드사 홈페이지(PC)** 에서 "이용명세서 PDF" 다시 받기 — 앱 화면과 달리 마스킹 없이 나오는 경우가 많음
2. **은행에서 "예금잔액증명서" 발급** (계좌개설확인서 말고 다른 서류. 수수료 500~1000원 정도)
3. 본인 명의로 된 **도시가스 요금 고지서**가 있는지 확인
4. (자취/전월세인 경우) **임대차 계약서** — 이름·주소 다 나옴

이 중 하나 해결되면 → 콘솔의 "본인 확인" → "시작하기" → 그 서류 업로드 (카드번호·거래내역 등 불필요한 정보는 검은 박스로 가리고)

**본인 확인 말고 남은 계정 체크리스트 2개도 있음:**
- Android 휴대기기 액세스 확인
- 연락처 전화번호 인증

이 셋 다 끝나야 앱을 실제로 출시할 수 있습니다.

## 다음 순서 (본인 확인 끝난 뒤)

### 3단계 — 스토어용 빌드 다시 만들기

시간이 지났으니 새로 빌드하는 게 안전합니다. 컴퓨터 터미널, `dotted` 폴더에서:
```
git pull
eas build -p android --profile production
```
15~30분 대기. 끝나면 `.aab` 파일 링크가 나옵니다 (콘솔에 업로드할 파일, 다운로드 불필요).

### 4단계 — 콘솔에서 앱 만들기

1. 플레이 콘솔 → **"앱 만들기"**
2. 앱 이름: `dotted — a quiet place to write` (영어로 확정, `docs/store-listing.md` 참고)
3. 기본 언어: 영어(미국) — 앱 화면 자체가 영어라 이걸로 확정함
4. 앱/게임: 앱
5. 무료/유료: **무료**

### 5단계 — 왼쪽 메뉴 "정책 및 프로그램 설정" 채우기

| 항목 | 답 |
|---|---|
| 앱 액세스 | 모든 기능을 제한 없이 이용할 수 있음 |
| 광고 | 아니요, 광고 없음 |
| 콘텐츠 등급 | 설문 진행, 대부분 "아니오" → 전체 이용가 나옴 |
| 타겟층 | 폭넓게, 만 13세 미만 전용 아님 |
| 뉴스 앱 | 아니요 |
| 데이터 보안 | 아래 표 참고 |
| 개인정보처리방침 | `https://mks1768-design.github.io/dotted/privacy-policy` |
| 정부 앱 | 아니요 |

**데이터 보안 항목:**
- 사용자 콘텐츠(노트)는 기기에만 저장 — "수집" 아님
- AI 기능(Improve/Scan) 쓸 때만, 그 내용이 Anthropic으로 전송됨 — "제3자 공유"에 이렇게 명시
- 전송 중 암호화(HTTPS) — 예
- 앱 삭제 시 전부 삭제됨

### 6단계 — 스토어 등록정보 채우기

왼쪽 메뉴 "스토어 설정" → "기본 스토어 등록정보":
- 앱 이름 / 짧은 설명 / 자세한 설명 → `docs/store-listing.md` 그대로 복사
- 아이콘 → `store-assets/icon-512.png`
- 그래픽 이미지 → `store-assets/feature-graphic-1024x500.png`
- 스크린샷 → 최소 2장 (폰에서 직접 찍은 걸로)
- 카테고리: 생산성

### 7단계 — 비공개 테스트 (필수 관문)

신규 개인 계정은 정식 출시 전에 **비공개 테스트를 먼저** 거쳐야 합니다.

1. 왼쪽 메뉴 "테스트" → "비공개 테스트"
2. 3단계에서 만든 `.aab` 업로드
3. 테스터 이메일 목록 추가 (12~20명, 콘솔에 정확한 인원 표시됨)
4. 테스터들에게 참여 링크 보내기 → 각자 "테스터 되기" 눌러야 함
5. **최소 14일 유지**

### 8단계 — 정식 출시

14일 지나고 조건 충족되면:
1. "프로덕션" → "새 버전 만들기"
2. `.aab` 업로드 (재사용 가능)
3. 출시 노트 짧게 작성
4. 검토 제출
5. 구글 심사 (며칠~1~2주)

통과하면 진짜 스토어에 올라갑니다. 끝.
