# dotted — 출시까지 해야 할 것

전부 계정·결제·실기기가 필요한 일이라 대신 해드릴 수 없는 항목들입니다.
위에서부터 순서대로 하시면 됩니다. 각 단계는 앞 단계가 끝나야 의미가 있어요.

---

## 0단계 · 먼저 알아야 할 것 (결정 사항)

**이 앱은 BYOK(Bring Your Own Key) 구조입니다.** 서버가 없어서 AI 비용을
제가 대신 낼 수 없고, 그래서 앱을 쓰는 **사람마다 각자 Anthropic 키를 만들어
넣어야** AI 기능이 돌아갑니다.

- 장점: 서버 비용 0원, 사장님이 남의 AI 요금을 떠안지 않음
- 단점: 플레이스토어에서 받은 일반 사용자 대부분은 키를 못 만듭니다.
  실질적으로는 "AI를 아는 사람용 앱"이 됩니다.

노트 작성 / 사진 노트 / 보드 뷰 / 백업은 키 없이도 전부 동작하니,
**AI는 보너스 기능**으로 스토어 설명을 쓰는 게 정직하고 리뷰 평점에도 낫습니다.

---

## 1단계 · Anthropic API 키로 AI 실제 테스트

### 1-1. 키 발급

1. https://console.anthropic.com 가입
2. **Billing → 크레딧 충전 (최소 $5)** ← 이걸 건너뛰면 키를 만들어도
   `credit balance is too low` 에러만 납니다. 무료 체험 크레딧이 없어요.
3. **API keys → Create Key** → `sk-ant-...` 복사
   (한 번만 보여줍니다. 못 보면 새로 만들어야 해요.)

### 1-2. 앱에 넣기

앱 실행 → 우측 상단 **Settings** → **AI** 섹션 펼치기 → 키 붙여넣고 **Save**

### 1-3. 반드시 해볼 테스트

| 무엇을 | 어떻게 | 뭘 봐야 하나 |
|---|---|---|
| Improve — 짧은 글 | 2~3줄 노트 → Polish | 원래 말투가 살아있나, 이상하게 딱딱해지지 않았나 |
| Improve — **긴 글** | 800자 이상 노트 → Polish | **중간에 잘리지 않나** ← 이번에 고친 부분 |
| Improve — Concise | 긴 노트 → Concise | 너무 짧게 뭉개지 않나 |
| Improve — 직접 지시 | "존댓말로 바꿔줘" 같은 걸 직접 입력 | 지시를 따르나 |
| Scan — 정상 | 책 한 페이지 실제 촬영 | 원문이 제대로 옮겨지나, 설명이 쓸모있나 |
| Scan — **흐린 사진** | 일부러 초점 안 맞게 촬영 | "안 보인다"고 말하나, 아니면 지어내나 ← 이번에 고친 부분 |
| Scan — 빈 종이 | 백지 촬영 | 에러 없이 넘어가나 |
| 품질 토글 | Standard ↔ High 바꿔가며 같은 글 | 차이가 돈값을 하나 |
| 갤러리 경로 | "Choose an existing photo" | 갤러리가 열리나 |
| 카메라 권한 거부 | 권한 물을 때 "거부" 누르기 | 안내 문구가 뜨고 갤러리로 갈 수 있나 |

### 1-4. 비용 감각

- Standard = Claude Sonnet 5 (입력 $3 / 출력 $15, 100만 토큰당)
- High = Claude Opus 5 (입력 $5 / 출력 $25)
- 노트 한 번 다듬기 ≈ 1~3센트. 사진 스캔은 이미지가 들어가서 조금 더 비쌉니다.
- **$5면 테스트하기엔 충분합니다.** 콘솔에서 실시간 사용량이 보이니
  테스트 끝나고 한 번 확인해 보세요.
- 콘솔 **Limits**에서 월 상한을 걸어두면 사고를 막을 수 있습니다.

## 2단계 · 실기기에서 확인 (빌드 전)

웹 미리보기에서는 카메라가 파일 선택창으로 나옵니다. 진짜 카메라는 폰에서만 확인돼요.

### 가장 빠른 방법 — Expo Go

```bash
npx expo start
```

폰에 **Expo Go** 앱 설치 → 터미널의 QR 코드 스캔 → 같은 Wi-Fi에 있으면 바로 실행됩니다.

### 폰에서 확인할 것

- [ ] 스플래시 → 온보딩 → 홈 흐름이 매끄러운가
- [ ] **"Capture page"가 진짜 카메라를 여는가** (핵심)
- [ ] 촬영 후 되돌아와서 스캔 결과가 뜨는가
- [ ] 사진 노트에서 갤러리 선택이 되는가
- [ ] 앱을 완전히 껐다 켜도 노트가 남아있는가
- [ ] API 키가 껐다 켜도 남아있는가 (SecureStore)
- [ ] 백업 Export → 파일 공유가 되는가 / Import로 되돌아오는가
- [ ] 노트 Share가 카카오톡 등으로 나가는가
- [ ] 글씨 크기를 시스템에서 크게 해도 레이아웃이 안 깨지는가
- [ ] 뒤로가기 제스처가 어색하지 않은가

> Expo Go에서 잘 되면 대부분 실제 빌드에서도 됩니다. 스플래시 화면과
> 아이콘만은 Expo Go에서 자기 것으로 보이니, 3단계 빌드 후에 다시 확인하세요.

## 3단계 · EAS 빌드 (설치 가능한 앱 만들기)

### 3-1. 준비

1. https://expo.dev 가입 (무료)
2. ```bash
   npm install -g eas-cli
   eas login
   eas build:configure
   ```
   → `eas.json`이 생깁니다. (지금 저장소에는 없습니다 — 이 명령이 만들어요.)

### 3-2. 테스트용 APK 먼저

```bash
eas build -p android --profile preview
```

- 빌드는 Expo 서버에서 돌고 15~30분 걸립니다. 무료 등급은 대기열이 있어요.
- 끝나면 다운로드 링크가 나옵니다 → 폰에 직접 설치해서 2단계 체크리스트를 다시 한 번.
- **여기서 아이콘 / 스플래시 / 앱 이름이 제대로 나오는지 꼭 확인하세요.**

### 3-3. 스토어용 AAB

```bash
eas build -p android --profile production
```

플레이스토어는 APK가 아니라 **.aab**를 받습니다. 이걸 업로드하게 됩니다.

## 4단계 · 구글 플레이 콘솔

### 4-1. 계정

- https://play.google.com/console — **개발자 등록비 $25 (평생 1회)**
- 개인 계정이면 신분 확인 절차가 있고 며칠 걸릴 수 있습니다.

### 4-2. ⚠️ 신규 개인 개발자 비공개 테스트 요건

최근 몇 년 사이 생긴 규정입니다. **개인(personal) 계정으로 새로 등록하면,
정식 출시 전에 비공개 테스트를 일정 인원 × 14일 연속으로 돌려야 합니다.**
(인원 기준이 20명 → 12명으로 바뀌는 등 계속 조정돼 왔으니, 콘솔에
표시되는 현재 기준을 직접 확인하세요.)

- 테스터는 **실제 구글 계정**이 필요하고, 14일 동안 실제로 참여해야 합니다.
- 이걸 모르고 있다가 출시 직전에 막히는 경우가 많습니다. **미리 사람을
  모아두세요.**
- 사업자(organization) 계정은 이 요건이 적용되지 않습니다.

### 4-3. 앱 만들고 채워야 할 것

**스토어 등록정보**
- [ ] 앱 이름 (30자) — "dotted"가 이미 있는지 스토어에서 검색해 보세요
- [ ] 간단한 설명 (80자)
- [ ] 자세한 설명 (4000자)
- [ ] 앱 아이콘 **512×512 PNG**
- [ ] 그래픽 이미지 **1024×500**
- [ ] 휴대전화 스크린샷 **최소 2장** (실제로는 4~6장 권장)

**정책·양식**
- [ ] 콘텐츠 등급 설문
- [ ] 타겟 사용자층 / 광고 포함 여부 (광고 없음)
- [ ] **데이터 보안 양식** ← 아래 4-4 참고. 대충 쓰면 나중에 앱이 내려갑니다.
- [ ] **개인정보처리방침 URL (필수)** ← 아래 4-5 참고
- [ ] 앱 서명 — Play App Signing 그대로 쓰시면 됩니다

### 4-4. 데이터 보안 양식 — 정직하게 쓸 내용

이 앱이 실제로 하는 일입니다. 그대로 신고하세요:

| 항목 | 사실 |
|---|---|
| 노트 본문·사진 | **기기에만 저장** (AsyncStorage). 서버 없음 |
| API 키 | 기기의 보안 저장소(SecureStore)에만 저장 |
| 계정·로그인 | 없음 |
| 광고·추적 | 없음 |
| 분석 도구 | 없음 |
| **외부 전송** | **AI 기능을 쓸 때만** 노트 본문 또는 촬영한 사진이 **Anthropic API로 전송**됨. 사용자가 자기 키를 넣고 버튼을 눌렀을 때만 발생 |

마지막 줄이 핵심입니다. "데이터를 전혀 수집하지 않음"이라고 쓰면 **거짓 신고**가
됩니다. "앱 기능 제공을 위해 전송되며, 저장하지 않음"으로 신고하세요.

### 4-5. 개인정보처리방침

URL이 **반드시** 있어야 합니다. 무료로 만드는 법:

- 이 저장소에 `docs/privacy-policy.md`를 만들고 **GitHub Pages**를 켜면
  `https://mks1768-design.github.io/dotted/privacy-policy` 같은 주소가 나옵니다.
- 내용은 4-4 표를 문장으로 풀면 됩니다. **초안이 필요하시면 말씀하세요 —
  이건 제가 써드릴 수 있습니다.**

## 5단계 · 업데이트할 때마다

`app.json`에서 두 값을 올려야 합니다. 안 올리면 플레이 콘솔이 업로드를 거부합니다.

```json
"version": "1.0.1",              // 사람이 보는 버전
"android": { "versionCode": 2 }  // 올릴 때마다 +1, 절대 되돌릴 수 없음
```

## 제가 대신 할 수 있는 것 / 없는 것

**못 하는 것** — 계정, 결제, 실기기가 필요해서입니다.
- Anthropic 크레딧 충전, 실제 키로 AI 품질 확인
- 실기기에서 카메라·저장·공유 확인
- EAS 빌드 실행 (expo.dev 계정 필요)
- 플레이 콘솔 등록비 결제, 양식 제출, 테스터 모집

**할 수 있는 것** — 필요하면 말씀만 하세요.
- 개인정보처리방침 초안 작성
- 스토어 설명문(짧은 설명 / 자세한 설명) 한국어·영어 초안
- 스크린샷용 화면 다듬기, 그래픽 이미지 시안
- `eas.json` 미리 만들어 두기
- 테스트 중에 나온 버그 수정
- 512×512 아이콘 등 필요한 크기로 에셋 뽑기
