# Play Store listing copy

Copy these straight into the Play Console "Store settings" fields.

---

## App name (30 characters max)
```
dotted — a quiet place to write
```

## Short description (80 characters max)
```
Notes, journals, scanned pages. All on your phone. No account, no ads.
```

## Full description (4000 characters max)

```
Open it and start writing. That's the whole setup.

dotted is a notepad for quick notes, journal entries, photo notes, and pages you scan straight out of a book. No account, no sign-up, no syncing.

WHAT YOU CAN DO

• Write notes and journal entries
• Add a photo with a caption
• Pick from seven paper styles, plain to dotted
• Scan a page with your camera and keep it as a note
• Browse as a list, or switch to a board view when you have a lot of photos
• Share a note to any other app
• Back everything up to a file and restore it whenever

EVERYTHING STAYS ON YOUR PHONE

There is no dotted server. Your notes are stored on your device and nowhere else. No ads, no tracking, no analytics, no account to make. Delete the app and everything goes with it.

AI, ONLY IF YOU WANT IT

Two features use AI. Improve rewrites a note for you. Scan can read a page back to you in plain language.

Both run on Claude, from Anthropic. Since dotted has no server of its own, they use your own Anthropic API key: a one-time setup that takes about five minutes, and the app walks you through every step. You pay Anthropic a few cents per use, nothing to us.

Skip it and everything else works exactly the same.
```

### Why it's written this way
- First two lines are what shows before "Read more" — they carry the hook and the main keywords.
- "notepad", "notes", "journal", "scan" appear naturally throughout for Play Store search.
- Short sentences, no em dashes, bullet list in the middle — real listings get skimmed, not read.
- Privacy is the actual differentiator against Keep/Notion, so it gets its own section above the AI section.
- AI is placed last and framed as optional, so the API-key requirement never reads as a catch.
