# 플레이스토어 등록 문구 초안

콘솔의 "스토어 등록정보"에 그대로 복사해서 쓰시면 됩니다. 마음에 안 드는 부분은 편하게 고치세요.

---

## 앱 이름 (30자 이내)
```
dotted — 조용히 쓰는 메모
```

## 간단한 설명 (80자 이내)
```
점 하나로 시작하는 메모장. 글, 사진, 스캔한 페이지를 한 곳에 — AI는 원하면 더하는 옵션.
```

## 자세한 설명 (4000자 이내)

```
dotted는 화려한 기능보다 "쓰기 좋은 느낌"을 먼저 생각한 메모 앱입니다.

✏️ 쓰기
글로 남기거나, 사진 위에 짧은 캡션을 남기거나, 취향에 맞는 종이 스타일을 골라 쓸 수 있습니다.

📚 모아보기
목록으로 정리해서 보거나, 사진 노트가 많다면 보드(핀터레스트 스타일) 뷰로 한눈에 훑어볼 수 있습니다.

📷 페이지 스캔
책이나 문서의 한 페이지를 카메라로 찍어서 노트에 바로 남길 수 있습니다.

💾 내 것으로만
계정도, 로그인도, 서버도 없습니다. 작성한 모든 내용은 이 기기에만 저장되고, 원할 때 백업 파일로 내보내거나 불러올 수 있습니다.

✨ AI는 선택 사항
글을 다듬거나(Improve) 스캔한 페이지를 설명해주는(Explanation) 기능은 Claude(Anthropic)를 사용합니다. dotted에 서버가 없기 때문에, 이 기능을 쓰려면 본인의 Anthropic API 키를 앱 안에서 직접 발급받아 등록해야 합니다 — 앱 안내를 따라가면 5분 정도 걸립니다. 이 기능을 쓰지 않아도 dotted의 나머지 기능은 전부 그대로 사용할 수 있습니다.

정리하면:
• 메모 앱으로 완결됨 — AI 없이도 충분
• 모든 데이터는 기기에만 저장
• 광고 없음, 추적 없음, 회원가입 없음
```

## 그래픽 자산 체크리스트

| 항목 | 규격 | 상태 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG | `assets/icon.png`을 리사이즈해서 준비 필요 |
| 그래픽 이미지(Feature graphic) | 1024×500 PNG/JPG | 별도 제작 필요 — 요청하시면 시안 만들어드립니다 |
| 휴대전화 스크린샷 | 최소 2장, 권장 4~6장 | 앱 실행해서 각 화면 캡처 |

512×512 아이콘이나 1024×500 그래픽 이미지가 필요하시면 말씀해 주세요, 지금 있는 아이콘 에셋으로 바로 만들어드릴 수 있어요.
