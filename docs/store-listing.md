# Play Store listing copy

Copy these straight into the Play Console "Store settings" fields.

---

## App name (30 characters max)
```
dotted — a quiet place to write
```

## Short description (80 characters max)
```
Notes and journals that stay on your phone. Nothing to sign up for.
```

## Full description (4000 characters max)

```
A notepad app. You open it and write. There's no account to make and nothing to set up first.

A note can be plain text, a journal entry, a photo with a caption, or a page you scanned out of a book with the camera. There are seven paper styles if you care about that sort of thing, and a board view for when you have enough photo notes that a plain list stops being useful.

What's in it:

• Notes and journal entries
• Photo notes with captions
• Seven paper styles
• Camera scanning for pages from books and documents
• List view and board view
• Share a note to any other app
• Backup and restore from a file

Everything stays on your phone. dotted doesn't have a server, so there's nowhere else for your notes to go. No ads, no tracking, no analytics. Deleting the app deletes the notes with it, which is why the backup file exists.

Two things use AI. Improve rewrites a note for you. Scan can read a page back in plain language. Both run on Claude, from Anthropic, and since there's no dotted server they use your own Anthropic API key. It's a one-time setup, takes about five minutes, and the app walks you through it. You pay Anthropic a few cents per use.

If you'd rather not bother with that, don't. The rest of the app doesn't need it.
```

### Why it's written this way
- No shouting headers. Sentence-case running prose with one short list where scanning actually helps.
- No em dashes and no three-item negations ("no X, no Y, no Z") — the two clearest tells of machine-written copy.
- Sentence lengths vary on purpose. Some are short. One runs long with an aside in the middle.
- "notepad", "notes", "journal", "scan" still appear naturally throughout for Play Store search.
- The API-key requirement is stated plainly and last, with a shrug at the end rather than a sales close.
