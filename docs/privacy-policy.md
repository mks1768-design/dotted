# dotted Privacy Policy

Last updated: 2026-07-30

**dotted** is a personal notes app with no server. This is a complete account of what it does.

### What is stored
- Your notes (text, photos, scanned pages) are stored **only on this device**.
- If you add an Anthropic API key, it is stored only in this device's secure storage (Android Keystore).
- dotted has no accounts, no sign-up, no login. We hold no information that identifies you.

### What leaves the device
dotted has no server of its own. Data leaves the device in exactly two cases, only when you tap the corresponding button:

| Feature | What's sent | Sent to |
|---|---|---|
| **Improve** (rewrite a note) | That note's text | Anthropic (using your own API key) |
| **Scan** (read a page) | The one photo you captured | Anthropic (using your own API key) |

If you never use these two features, nothing leaves the device. Nothing passes through a dotted server — there isn't one. See [Anthropic's privacy policy](https://www.anthropic.com/privacy) for how they handle what's sent to them.

### Advertising and tracking
- No ads
- No analytics
- No data shared with third parties

### Deleting your data
- Uninstalling the app deletes every note and key stored on the device.
- The API key alone can be removed anytime from Settings.

### Contact
Questions about this policy can be raised as an issue on the [GitHub repository](https://github.com/mks1768-design/dotted).
